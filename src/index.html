사용 가이드

이 도구는 qPCR raw data나 일반 실험 데이터를 넣으면 브라우저 안에서 계산하고 그래프를 그립니다. 먼저 왼쪽에서 데이터와 설정을 고른 뒤, 오른쪽 그래프를 확인하고 파일로 저장하세요.

일반 그래프 만들기
  1. 엑셀/CSV 파일을 올리거나 표를 붙여넣습니다.
  2. 앱이 컬럼명과 값 형태를 보고 bar, grouped bar, line, scatter, box, violin, heatmap, dose-response, volcano 중 하나를 자동 추천합니다.
  3. Columns에서 X, Y, Group, Label 컬럼을 직접 바꿀 수 있습니다.
  4. 필요하면 자동 인식해서 그리기, X/Y 바꾸기, 그래프 종류 버튼으로 빠르게 조정합니다.
  5. 그리기를 눌러 미리보기를 업데이트합니다.
qPCR 그래프 만들기
  1. qPCR 탭을 선택합니다.
  2. 장비에서 export한 XLSX/CSV/TSV 파일을 올리거나 표를 붙여넣습니다. raw 형식의 Well, Target, Sample, Ct/Cq와 QuantStudio Sample Results를 자동 구분합니다.
  3. Reference gene에는 GAPDH, ACTB 같은 housekeeping gene을 고릅니다.
  4. Calibrator에는 기준 sample, 예를 들어 Control, WT, HELA를 고릅니다.
  5. BioRep/TechRep 구조와 error bar를 확인한 뒤 분석을 누릅니다.
Raw data에서는 target Ct/Cq가 undetermined이면 기본값 40으로 처리합니다. QuantStudio Sample Results에서는 B1/B2/B3를 biological replicate로 사용하며 Biogroup Results는 replicate 계산에 사용할 수 없습니다. 2^-ΔΔCq는 target/reference assay의 증폭 효율이 충분히 유사하다는 가정을 사용합니다.
그래프 꾸미기와 저장
  • Format 또는 설정의 Figure/Axes에서 제목, X/Y축 이름, 색상, 범례 위치를 바꿀 수 있습니다.
  • 일반 그래프에서는 X값/Y값을 log10, log2, ln, sqrt, z-score, percent 등으로 변환할 수 있습니다.
  • 범례는 Right, Top, Bottom, Left, Floating, Hide 중에서 선택할 수 있고, 그래프 위에서 직접 드래그해 옮길 수도 있습니다.
  • 축과 범례 Axes에서 가로/세로 보조선을 켜고 끌 수 있습니다.
  • 축과 범례 Axes에서 cutoff 같은 기준선 위치와 라벨도 함께 설정할 수 있습니다.
  • PNG는 이미지 저장용, SVG는 Illustrator 편집용, CSV/XLSX는 계산 결과 보관용으로 쓸 수 있습니다.
